# Run Construction AI Full App v8.0

## 1. Install
    pip install -r requirements.txt

## 2. Seed demo data
    python seed_live_demo.py

## 3. Start full app
    uvicorn full_app:app --host 0.0.0.0 --port 8000

## 4. Open
    http://localhost:8000

This build is a fuller clickable web application surface over the existing Construction AI backend and intelligence modules.
