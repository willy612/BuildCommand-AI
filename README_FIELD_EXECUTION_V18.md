# Construction AI — Field Execution + Subcontractor Portal v1.8

## Added

### Field Execution Command
- morning command workspace
- activity-linked field updates
- progress/blocker/safety/quality/inspection/delivery/coordination updates
- proposed percent-complete capture
- daily superintendent report
- tomorrow-readiness workspace foundation

### Automatic Constraint Intelligence
Field or subcontractor statements containing likely blocking conditions can generate
a proposed constraint with:
- category
- affected schedule activity
- subcontractor
- source
- responsible party
- required-by date
- schedule exposure
- recommended action
- confidence
- superintendent review status

Nothing automatically becomes a controlling project constraint without review.

### Subcontractor Portal
Limited subcontractor users can:
- access only assigned projects
- view their lookahead commitments
- confirm or reject dates
- report material issues
- report manpower issues
- report access issues
- request information
- enter crew/material/equipment readiness
- explain delays

Non-confirmed responses can create constraint proposals for superintendent review.
