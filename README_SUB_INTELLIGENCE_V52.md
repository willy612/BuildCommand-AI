# Construction AI — Subcontractor Intelligence v5.2

## Goal
Understand subcontractor operating behavior in context so the project team can intervene earlier.

## Signals
Initial metrics:
- commitment response reliability
- start-date reliability proxy
- manpower reliability
- production reliability
- early-warning behavior
- open/closed quality items

## Context score
A transparent context score combines those signals.

This is NOT:
- a vendor grade
- a procurement blacklist
- an automatic award recommendation
- a blame score

Upstream GC/owner/design constraints still matter.

## Superintendent Command integration
Where an activity has an assigned subcontractor, Daily Superintendent Command can show
subcontractor context alongside the action.

Example:
"Manpower reliability has been low on this project and the activity starts in 10 days.
Confirm crew plan now."

## Company memory
Subcontractor context can be captured as company learning evidence.
Future versions should distinguish:
- trade
- project type
- region
- phase
- superintendent
- activity type
- season
- project constraints

## Privacy
Subcontractor intelligence remains inside the contractor/company boundary.
It should never expose another contractor's private observations.
