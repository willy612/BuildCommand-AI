# Construction AI — Field-First UX v3.1

v3.1 focuses on how superintendents and subcontractors would actually use the product.

## Added

### Mobile-friendly activity cards
The home/lookahead views use compact activity cards rather than dense tables.

### Visual 6-week lookahead
Activities are grouped into six week columns to make field planning easier to scan.

### Quick field update
The field screen is optimized for short updates and device dictation.
Users can use the phone keyboard microphone now; a dedicated speech-to-text service can be plugged in later.

### Field photo capture
Superintendents can:
- take a jobsite photo from the device camera
- upload an existing photo
- attach it to a schedule activity
- add a caption/observation
- persist it in the project field record

### Cleaner subcontractor portal
The portal language is simplified around:
- upcoming work
- commitments
- issues
- readiness
