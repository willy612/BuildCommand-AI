# Construction AI acceptance criteria

## Product workflow
A pilot must prove the complete daily loop:
1. superintendent opens Daily Command;
2. sees prioritized evidence-backed actions;
3. sees predictive risks and why;
4. routes coordination to responsible parties;
5. records subcontractor commitment/response;
6. records installed production;
7. detects pace/drift risk;
8. tests recovery options;
9. human approves selected recovery;
10. outcome is measured;
11. company memory updates;
12. playbook can improve the next comparable situation;
13. leadership sees portfolio-level exception reporting.

## Success measures for pilot
Define with pilot customer before launch:
- daily active superintendent usage
- action closure time
- commitment response rate
- constraint aging
- forecast accuracy
- percentage of risk alerts reviewed before impact
- recovery prediction error
- playbook usefulness feedback
- reduction in manual coordination effort

No metric should be marketed as proven until measured on real deployments.
