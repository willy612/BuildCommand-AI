# 60-day field pilot

## Weeks 1-2 — Setup
Choose 1-2 active projects and 2-4 superintendents.
Import schedules, subcontractor directory, lookahead, constraints and production units.
Baseline current coordination effort and schedule forecast quality.

## Weeks 3-4 — Daily Command
Run Daily Superintendent Command every workday.
Measure whether surfaced actions are relevant, timely and correctly owned.
Do not automate external communications without approval.

## Weeks 5-6 — Predict + Recover
Review predictive risk each morning.
For meaningful risks, compare sandbox/optimizer recovery scenarios with superintendent and scheduler judgment.
Record decisions and actual outcomes.

## Weeks 7-8 — Learn
Review company memory and playbook candidates.
Measure which recommendations helped.
Review false positives, false negatives and workflow friction.

## Pilot exit decision
Proceed only if the product demonstrates repeated field value, safe tenant isolation,
acceptable data quality and a workflow superintendents will actually use.
